# skyMart 🛒☁️

Welcome to **skyMart**! This is a modern e-commerce web application built with React and Vite.

## 🚀 Live Demo

Check out the live application here:  
**👉 [https://skymart-three.vercel.app/](https://skymart-three.vercel.app/)**

## ✨ Features
- **User Authentication:** Secure login and registration.
- **Product Dashboard:** Browse the latest products and categories.
- **Protected Routes:** Certain pages are secured and only accessible to logged-in users.
- **Responsive Design:** Beautifully styled for all devices.

## 🛠️ Tech Stack
- **Frontend Framework:** React
- **Build Tool:** Vite
- **Routing:** React Router (v6+)
- **Icons:** Lucide React
- **Deployment:** Vercel

## 💻 Running Locally

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
